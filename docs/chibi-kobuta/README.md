## キャラクター仕様

- 体の縦横比はたぬきと同じ大福形。首・くびれなし
- 体全体が淡いピンク
- 小さな三角の立ち耳（内側は少し濃いピンク）
- 目は小さな黒い点。隈取りは無い。頬に少し濃いピンクの頬紅
- 顔の中央に少し濃いピンクの小さな楕円の鼻（鼻の穴は点2つ）
- 腕のでっぱり・足の突起は体と同じピンク（伸ばさない）
- 体の右下からくるんと巻いた小さなピンクのしっぽ
- 線・文字・画風はちびしろたぬきと同じ

## 編集用テンプレート（コピペ用）

```

【変えないもの(最優先)】
・キャラクターの輪郭の形、大きさ、横幅と高さの比率
・耳、鼻、しっぽ、腕のでっぱり、足の突起の形と大きさ
・線のタッチと塗り

【変えるもの】
・表情:(表情)
・腕のでっぱり:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:「む――」を消し、キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターの体の色はそのまま
```

## キャラ固有の注意

- ピンク系の小物は体と溶けるので避ける（ちびしろたぬきの冬パックの「淡いピンクの毛布」などは
  別の色に置き換える）
- 体色がミント背景とはっきり分かれるので、切り抜きは4キャラの中で一番安定する見込み
