# おにぎり関（引き継ぎ資料）

おにぎり×力士モチーフのキャラ（ユーザー提供のベース画像から作る。名前は仮）。作り方は
ちびキャラと同じ「参照画像を1枚ずつGeminiに編集させる方式」で、後処理も
`docs/chibi-shirotanuki/README.md` の確定コマンドを使う。ここにはキャラ固有の内容を書く。

## 画像ファイル

| ファイル | 中身 | 使い方 |
|---|---|---|
| `ref_edit_base.png` | 白背景・正面立ち（1632×2176px）。上に文字は無い | **Geminiに添付するのはこれ1枚だけ** |

ちびキャラのベース画像と違い、上に「む――」が無い。テンプレートは「キャラクターの上に書く」形にしてある。

## キャラクター仕様

- 白いごはんの三角おにぎりの体。表面にうすいグレーのごはん粒の模様。首・くびれなし
- 頭のてっぺんに、海苔を巻いたごはんのまげ（大銀杏ふう）
- 体の下に海苔のまわし（濃いグレー、前に下がり）
- 目は小さな黒い点、口は「ω」の形。眉は無い
- 腕は体の表面に描かれた小さな曲線、足は体の下の小さな突起2つ（伸ばさない）
- 線は濃い茶色の太めで均一、のっぺりした塗り

```
・目の形、大きさ、位置、向き(目は一切変えない。眉は描かない)
・口の形
・頭の上の海苔のまげ、海苔のまわし、ごはん粒の模様
・腕の曲線、足の突起の形と大きさ
・線のタッチと塗り

【変えるもの】
・表情:(表情)
・腕:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターの体の中は白のまま
```

## キャラ固有の注意

- 体が白いので、**背景が白のまま出た画像は切り抜けない**（白い体ごと消える）。必ず作り直す
- **目・眉・口の指示は入れない**（変えるとキャラが大きく変わるため。ちびキャラでの経験から最初から外している）。
  表情は基本「変えない」で、ポーズ（腕）・小物・エフェクトで差を出す
- 四股（#6）は足を少し上げる指示で、正面立ちから一番離れる絵。崩れたら「足元に土ぼこりだけ」に減らす
- 水は淡い水色になりミント背景と一緒に消えるので、柄杓の水しぶきは描かせない
- 白い小物は体と溶ける。塩の粒は体から離して描かせる

## ポーズ別ベース画像（2026-10）

正面立ちのベース画像1枚の編集では力士らしい大きなポーズが崩れやすいため、ポーズ別のベース画像を
5枚作り、該当するスタンプはそのポーズのベース画像を添付して言葉・小物・エフェクトだけを変える。

- 作り方：新しいチャットに `ref_edit_base.png` だけを添付し、下のプロンプトを貼る。数回生成して体型が崩れていないものを採用
- 採用前チェック：おにぎりの大きさ・目と口の位置・まげとまわしが元の画像と同じか（Claudeに送れば外接枠を測って比較する）
- 足を高く上げる・腕を長く描かれるのが典型的な失敗。足の高さはほどほどで妥協する
- 保存名は `pose_<名前>.png`（下表）。採用したらこのフォルダに入れ、表の「ベース」列で使い分ける

| 保存名 | ポーズ | 使うスタンプ |
