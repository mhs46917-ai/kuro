## キャラクター仕様

- 体の縦横比はたぬきと同じ大福形。首・くびれなし。耳は無く、頭の上は丸い
- 体は白
- 目は小さな黒い点に細い赤いリング（アイリング）。隈取りは無い
- 顔の中央に、小さくて太いピンクがかった赤のくちばし（鼻と口の代わり）
- 腕のでっぱり（羽）は白、足の突起は淡いピンク（伸ばさない）
- 体の右下から淡いグレーの短い尾羽
- 線・文字・画風はちびしろたぬきと同じ

## 編集用テンプレート（コピペ用）

```
添付画像を編集してください。
キャラクターを描き直さず、添付画像の線と塗りをそのまま使ってください。

【変えないもの(最優先)】
・キャラクターの輪郭の形、大きさ、横幅と高さの比率
・くちばし、目のまわりの赤いリング、羽のでっぱり、足の突起、尾羽の形と大きさ
・線のタッチと塗り

【変えるもの】
・表情:(表情) ※目とくちばしの開き方で表す
・羽のでっぱり:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:「む――」を消し、キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターの体の中は白のまま
```

## キャラ固有の注意

- 体が白いので、ちびしろたぬきと同じく**背景が白のまま出た画像は切り抜けない**
  （白い体ごと消える）。必ず作り直す
- 白い小物はNG（体と溶ける）。赤〜ピンクの小物はくちばしと紛れやすいので小さめに
- 口が無いので、「口を開けて笑う」などたぬき用の表情指示はくちばしの開閉に読み替える
- 4案の中で輪郭の変更が一番大きいキャラ。編集で体型が崩れたら、まず【変えるもの】を減らす
- 耳が無いので、たぬき用の設計で「耳」を使った指示はそのまま流用しない
