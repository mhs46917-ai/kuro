# シュールなギャグ漫画語彙ストック

ユーザーの好みである『ピューと吹く！ジャガー』（うすた京介）『ギャグマンガ日和』（増田こうすけ）
系統のシュールな笑い・語彙を、今後のスタンプパックの**セリフ・小物・演出**に反映するための
ストック集。作品名やキャラ名、実際の名台詞をそのまま使うと著作権・商標的にNGなので、
**「技法」を抽出して抽象化し、たぬき／ペンギンのオリジナル世界観に翻訳して使う**。

## 元ネタの傾向（リサーチ要約）

- 『ピューと吹く！ジャガー』：ナンセンスギャグ全開。キャラが本気でバカをやる、
  やたら大仰な悪態や決め台詞、ふざけた例え（「お前の前世 良くてクロレラ」等）が特徴。
  名言というより「迷言」。
- 『ギャグマンガ日和』：ゆるい絵柄と一話5分前後のハイテンポ、不条理なオチ。
  歴史上の人物をネタにしつつ独特な言い回しでシュールにする。「変態という名の紳士」のように
  **抽象的すぎる名詞化**がネットミーム化するパターンが多い。

## 抽出した技法（スタンプ設計に転用できる形）

1. **温度差ギャグ**：状況は深刻／異常なのに、口調だけ異様に落ち着いている・淡々としている。
   逆に些細なことに全力で取り乱す、というギャップでも成立する。
2. **大仰な言い回し**：日常の些細な出来事に、時代劇・儀式・法律文書のような固い言葉を当てる
   （例：「これにて一件落着とする」「異議は認めない」「〜の儀、執り行う」）。
3. **名詞化・概念化オチ**：状態や感情を「〜という概念」「〜という生き物」「〜現象」と
   ものものしく名付けて言い切る。中身は大したことがないほど効果的。
4. **誇張オノマトペ**：擬音を通常より長く・大きく書く／擬音そのものをセリフのように使う
   （例：「ズコー」「ガーン」「ドドドド」「シーン」を独立したセリフ扱いにする）。
5. **早口まくし立て→一言オチ**：長々と理屈をこねた直後に、一言で全部台無しにする（ノリツッコミ）。
6. **予想外の贅沢な単語選び**：安い・小さい・地味なものに、やたら格式高い形容をつける
   （例：石ころを「至宝」、日課のあくびを「儀式」と呼ぶ）。
7. **無駄に具体的な数字・固有名詞風表現**：「三日三晩」「歴代1位」のように、
   検証不能な誇張の数字を断定口調で言う。
8. **動物・物を擬人化して大真面目に語る**：小物やキャラの一部（しっぽ・くちばし等）に
   人格や意志があるかのように扱う。

## たぬき／ペンギンへの適用方針

- **たぬき（のほほん・やさしい系）**：技法1・3・6と相性がよい。普段が緩いキャラなので、
  一言だけ急に大仰になると温度差が効く。多用すると世界観が崩れるので**パックにつき1〜2個**に絞る。
- **ペンギン（無愛想・不機嫌系）**：技法2・4・5と相性がよい。無表情のまま大仰な言葉を
  言い切ると「無感情なのに大げさ」というギャップがキャラのコンセプトと噛み合う。

## 今後使える語彙・言い回しストック（オリジナル表現・随時追記）

日常フレーズをそのまま使うのではなく、ここから語彙だけ拝借してセリフを作る。

### 大仰な言い回し系
- 「これにて一件落着とする」
- 「異議は認めない」
- 「〜の儀、執り行う」
- 「本日をもって解散とする」
- 「以上、決定事項である」

### 名詞化・概念化系
- 「面倒くさいという名の生き物」
- 「やる気ゼロという概念」
- 「二度寝、それは正義」
- 「休日という名の儀式」

### オノマトペ独立セリフ系
- 「ズコー」
- 「シーン」（沈黙そのものをセリフとして描く）
- 「ドドドド…」
- 「ガーン」

### 誇張・断定口調系
- 「歴代1位のやる気の無さ」
- 「三日三晩、寝ずに悩んだ結果がこれ」
- 「宇宙が始まって以来の面倒くささ」

### 大げさな格付け系
- 「本日の至宝」（つまらない小物を指して）
- 「伝説になる予感」（大したことのない出来事に）

## 運用ルール

- ここに挙げた表現は**素材**であり、そのまま24枚に均等配置すると濃すぎて世界観が崩れる。
  1パックにつき1〜3枚程度の「アクセント」として混ぜるのが目安。
  他コマは既存の各パックのトーン（愚痴系／やさしい系など）を維持する。
- 新しいパックの企画時にこのファイルを見て、テーマに合いそうな技法・語彙があれば
  「【ポーズ】」のセリフ設計に混ぜる。ハマる語彙が見つかったら**都度この一覧に追記**していく
  （ユーザーの好みリサーチという性質上、ストックは増やしていく前提）。
- 実在の漫画の固有名詞・キャラ名・完全一致の名台詞は流用しない（著作権・商標リスク回避のため、
  技法だけ借りてオリジナルの言葉に翻訳する）。
