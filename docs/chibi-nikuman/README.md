## キャラクター仕様

- 体の縦横比はたぬきと同じ大福形。首・くびれなし。耳・しっぽは無い
- 頭のてっぺん中央に、肉まんの小さなひだ（ねじり目）。頭の丸い輪郭は保つ
- 体はほんのりクリームがかった白（RGBでおよそ 247,241,227）
- 目は小さな黒い点。隈取りは無い。頬に淡いピンクの丸い頬紅。口はたぬきと同じ
- 腕のでっぱり・足の突起は体と同じ色（伸ばさない）
- 線・文字・画風はちびしろたぬきと同じ

## 編集用テンプレート（コピペ用）

```
添付画像を編集してください。
キャラクターを描き直さず、添付画像の線と塗りをそのまま使ってください。

【変えないもの(最優先)】
・キャラクターの輪郭の形、大きさ、横幅と高さの比率
・頭のてっぺんのひだ、腕のでっぱり、足の突起の形と大きさ
・体のクリームがかった白
・線のタッチと塗り

【変えるもの】
・表情:(表情)
・腕のでっぱり:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:「む――」を消し、キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターの体の色はそのまま
```

## キャラ固有の注意

- 体が白に近いので、**背景が白のまま出た画像は切り抜けない**。必ず作り直す
- 白・クリーム色の小物は体と溶けるのでNG
- 湯気はベース画像には描かない。各スタンプの「追加」でだけ描かせる（キャラらしさの演出に使える）
- 頭のひだが大きくなって玉ねぎ・栗のようにとがったら、「ひだは小さな曲線3本だけ」と足して作り直す
