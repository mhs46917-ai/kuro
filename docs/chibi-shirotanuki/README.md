# ちびしろたぬき（引き継ぎ資料）

本家「まんまるしろたぬき」とは**別キャラ・別手法**のシリーズ。他のスタンプ（3×3グリッドで
新規生成）とはやり方が違い、**参照画像をGeminiに1枚ずつ編集させる方式**で作っている。
このシリーズの作業はこの資料を正として進める。

## 画像ファイル

| ファイル | 中身 | 使い方 |
|---|---|---|
| `ref_edit_base.jpg` | 白背景・正面立ち・上に「む――」の参照画像 | **Geminiに添付するのはこれ1枚だけ** |
| `ref_three_views.jpg` | 正面・側面・後ろ姿の三面図（ミント背景） | 確認用。Geminiには添付しない（3体並べて描かれる） |
| `published_everyday_words.jpg` | 公開済みパックのストア画面 | 画風・文字・サイズ感の完成見本 |

## キャラクター仕様

- 白い体。耳を除いた体全体の横幅と高さがほぼ同じ（1:1）の大福形。首・くびれなし
- 小さな丸い耳（内側は淡いグレー）
- 目のまわりに横長の大きなグレーの隈取り（丸く囲む。本家のように頬へ流さない）、目は小さな黒い点
- 腕は胴の左右の小さなでっぱり、足は体の下の小さな突起2つ（伸ばさない）
- しっぽは太く丸い、グレーと白の縞模様、体の右下から出る
- 仕上がりの画風：やわらかい色鉛筆タッチ、細めの濃い茶色の線、頬に赤み
- 文字：キャラの上に、キャラの横幅と同じくらいの手書きペン文字（濃い茶色）
- セリフは短く、のんびりした雰囲気

## なぜ編集方式なのか（試行錯誤の結論）

1. **鮮やかな青背景＋白フチ太字＋3×3**だと、Geminiがベクター・アプリアイコン調に寄せる → NG
2. ミント背景・手書き文字・画風ブロック・2×2にすると画風は寄ったが、**体型を文章で指示しても
   Geminiは2頭身の縦長キャラに戻す** → 比率が再現できない
3. **参照画像そのものを編集させる**と、輪郭・比率がほぼ動かず安定 → 採用
   - 代わりに1回1枚。正面立ちから大きく離れるポーズ（お辞儀・寝そべり・歩く・後ろ姿）は作れない。
     表情・腕のでっぱりの向き・小物・エフェクトで差を出す
   - 毎回新しいチャットに `ref_edit_base.jpg` だけを添付（生成結果を添付すると比率がずれる）
4. サイズ感はプロンプトでは変わらない。後処理の`fit_canvas`が余白いっぱいに拡大するため、
   **`--margin`で決める**（100で確定）
5. ダークモードで細い茶色の文字が読めないため、**白縁取り4px・不透明**（`--outline-alpha 255`。
   デフォルトの153だと半透明で効かない）

## 編集用テンプレート（コピペ用）

```
添付画像を編集してください。
キャラクターを描き直さず、添付画像の線と塗りをそのまま使ってください。

【変えないもの(最優先)】
・キャラクターの輪郭の形、大きさ、横幅と高さの比率
・耳、しっぽ、腕のでっぱり、足の突起の形と大きさ
・色鉛筆の線のタッチと塗り

【変えるもの】
・表情:(表情)
・腕のでっぱり:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:「む――」を消し、キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターの体の中は白のまま
```

- 崩れるときは【変えるもの】を減らす（まず腕を「変えない」に）
- 白い小物は体と溶けるのでNG（サンタ帽のふち等は淡い黄色に）。水色系はミント背景と一緒に消える
- 背景が白のまま出てきた画像は切り抜けない（白い体ごと消える）ので作り直す

## 後処理（確定コマンド）

```bash
python3 tools/line_sticker_prep.py 01.jpg 02.jpg ... \
  -o out --keep-all --margin 100 \
  --outline-width 4 --outline-rgb "255,255,255" --outline-alpha 255 --glow-alpha 0 \
  --main-index <mainにする番号>
```

- 1枚ずつの画像なので `--grid` は不要。採用する画像だけを並べて渡す
- 画像はまとめて（zipでも可）渡してもらえば一括処理できる
- ミニスタンプ用サイズ対応・コマごとのサイズ統一などツール改修はユーザー判断で不要とした
