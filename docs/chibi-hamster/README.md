## キャラクター仕様

- 体の縦横比はたぬきと同じ大福形。首・くびれなし。しっぽは無い
- 頭の上から体の外側は淡いクリーム色（やさしいオレンジベージュ）、口のまわりからお腹が白
- 小さな丸い耳（内側は淡いピンク）
- 目は小さな黒い点。隈取りは無い。頬に淡いピンクの丸い頬紅
- 腕のでっぱりと足の突起は淡いピンク（伸ばさない）
- 線・文字・画風はちびしろたぬきと同じ
- ベース画像では体の右側が少しふくらんでいる（たぬきのしっぽがあった名残）。
  ハムスターらしさとして許容。編集で左右対称に直させない

## 編集用テンプレート（コピペ用）

```
添付画像を編集してください。
キャラクターを描き直さず、添付画像の線と塗りをそのまま使ってください。

【変えないもの(最優先)】
・キャラクターの輪郭の形、大きさ、横幅と高さの比率
・耳、腕のでっぱり、足の突起の形と大きさ
・クリーム色と白の塗り分け
・線のタッチと塗り

【変えるもの】
・表情:(表情)
・腕のでっぱり:(腕) ※向きを少し変えるだけ。長くしない
・追加するもの:(追加) ※小さく描き、キャラクターに重ねない
・文字:「む――」を消し、キャラクターの上に「(言葉)」と書く。
 キャラクターの横幅と同じくらいの大きさの、やや太めの手書きペン文字、濃い茶色
・背景:白から淡いミントグリーンの無地に塗り替える。キャラクターのお腹の白はそのまま
```

## キャラ固有の注意

- クリーム色・ベージュ系の小物は体と溶けるので避ける（たぬきの「白い小物NG」と同じ理屈）
- しっぽが無いので、たぬき用の設計で「しっぽ」を使った指示はそのまま流用しない
- ハムスターらしい小物：ひまわりの種、小さなどんぐり。小物枠（5〜7種）に入れやすい
