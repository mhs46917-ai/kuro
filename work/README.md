# 作業の頼み方

## 流れ

1. 素材をチャットに添付する（または `work/inbox/` に置く）
2. やってほしいことを一言で伝える
3. 成果物を `work/output/` に出し、`work/LOG.md` に記録する

## できること

### 画像からデータを抽出する

読み取れるもの: 表のスクショ、レシート、請求書、名刺、手書きメモ、グラフ、PDFのページ

- 出力形式を指定してください（Excel / CSV / そのまま表で表示）
- 複数枚まとめて1つの表にすることもできます
- 読み取りに自信がないセルは印をつけて報告します。金額や数量は必ず目視で照合してください

依頼例: 「このレシート12枚を日付・店名・品目・金額の4列でExcelにして」

### Excelデータ分析

- 集計、クロス集計、ピボット相当の集計表
- 条件抽出、重複削除、表記ゆれの統一
- 複数ファイル・複数シートの結合、突合（差分抽出）
- グラフ作成、条件付き書式、体裁の整形
- 数式の埋め込み（値ではなく数式で残す指定も可）

依頼例: 「売上.xlsx を月別×商品カテゴリで集計して、棒グラフつきの新シートを追加して」

### 図・グラフ・画像の作成

- グラフ（棒・折れ線・円・散布図など）
- 図解、フロー図、構成図
- note用の見出し画像・サムネイル（文字主体のもの）

出力は PNG / SVG / PDF。サイズ指定できます（noteの見出し画像は 1280×670 が推奨）。

注意: 写真やイラストを生成するAI画像生成機能はこの環境にありません。
コードで描けるもの（図・グラフ・文字組み）が対象です。

### 文書作成

Word（.docx）、PowerPoint（.pptx）、PDF の作成・編集・読み取りに対応しています。

## 素材を渡すときのお願い

- Excelは元ファイルをそのまま。加工前のものがあるとやり直しが効きます
- 画像は解像度が高いほど読み取り精度が上がります。傾きは補正しなくて大丈夫です
- 個人情報が含まれる場合は事前に教えてください。出力時にマスクします
