## 1. 常体と敬体の混在

最大の特徴。無意識に使い分けておられます。**どちらかに統一すると別人の文章になる。**

| 内容 | 文体 | 例 |
|---|---|---|
| 一般化した観察・分析・断定 | **常体** | 「近さの量では、説明がつかないのだ。」「遠いのではなく、動かない。」 |
| 自分の経験・読者への語りかけ | **敬体** | 「転職する度に思うことがあります。」「踏み込んでいいと思います。」 |

分析で常体に落ち、自分の話に戻るとき敬体に上がる。この上下動が信用をつくっている。

---

## 2. 改行を多くとる。1行1文に寄せる

**※ここは以前の指示が間違っていたので訂正。** 校正で改行が大幅に増やされました。

- 列挙、畳みかけ、短い断定 → **1行1文**

```
ずっと敬語のまま。
当たり障りのないことしか言わない。
相手の話を、否定も肯定もせずに受け流す。
役割としてだけやりとりする。
```

- 説明が続く箇所だけ、2〜3文をまとめる
- **つながっている2〜3文は、空行を入れずに改行だけで続ける。** 話が変わるところで空行（2026/10 公開版で確認）

```
その後、店では無料レッスンを減らす方針になりました。
店として、おかしな判断ではありません。
営利事業である限り、無料のサービスはどこかで見直されます。
```

- 短い列挙も、空行なしで1つの塊にする（「40代。／主婦。／子どもが2人。」を続けて置く）
- ただし体言止めで細切れにしすぎた文はつなぐ（「応募もフロント。ゆくゆくは〜」→「応募もフロントでゆくゆくは〜」）
- 箇条書き記号（`-`）は使わない。改行そのものがリズム

## 3. 誠実感の正体

いい言葉を選んでいるからではなく、次の5つを毎回やっているから。
**特に1つ目が核。** 校正で入った直しは、ほとんどがこれでした。

### ① 言い切ったあと、必ず例外を残す

| 校正前 | 校正後 |
|---|---|
| 24時間ジムに来られる方の**多くは** | 24時間ジムに来られる方は**様々でしたが、多くは、** |
| その場所の基準をたまたま身体で覚えていただけ | 〜覚えていただけ、**またはフィーリングが合う相手なだけ** |
| 正直に言うと、私自身もやってきた側です | **シチュエーション次第で**私自身もやってきた側です |

**過度な一般化をしない。** 断定はする。したうえで、当てはまらない場合を1つ残す。
これが「この人は現場を見てきた人だ」という信頼をつくっている。

### ② 相手を悪者にしない

批判対象にも、まず善意を認める。「善意なのだ。善意なのだが、一方通行。」

### ③ きれいごとで終わらせない

模範解答のあとに、自分の実際の振る舞いを足す。
「私はあまりに酷い際は時々無視します。」「親しみのつもりで、逃げ場をなくしていました。」

### ④ 当時の心の声は、鍵括弧でそのまま置く

地の文で説明せず、当時頭にあった言葉を「」で、一行だけ置く。

```
「結局デザイナーは現場のことがわかってない」
現場からは決して直接言われることはない、ただその空気は常に感じていました。
```

```
「この人についていく選択は間違いだったかも」
数字より先に、危機感の差のほうがあった。
```

説明を足さない。置いて、次の文に移る。

### ⑤ 自己卑下の語は使わない

校正で **臆病 → 繊細** に直されました。
正直に書くが、自分を下げる言葉は選ばない。

### ⑥ 硬い語を避ける

校正で入った言い換え: **業界 → 環境** ／ **非対称 → 構図**
専門用語で決めない。日常の語で言う。

## 4. こちらが解釈を代筆しない ★最重要

**校正で2回とも削られたのが、こちらが補った「解釈」の文でした。**

| こちらが書いた解釈 | 校正後 |
|---|---|
| 止めてくれる人がいない場所にいると、人は伸びなくなる。 | **信頼という意味では誇らしい、ただモヤモヤが残る。** |

こちらの文は、一般論として整っている。だから削られる。
ご本人が置いたのは、**誇らしさとモヤモヤが同居している**という、
当人にしか書けない両義的な実感だった。

**下書きでは、事実と、ご本人が実際に思ったことだけを書く。**
「つまりこういうことだ」とまとめたくなったら、そこは空欄にして質問する。
一般論に落とした瞬間、その文はご本人のものではなくなる。

### 数字はぼかすことがある

校正で「会費は月8000円」→「会費は月**8000円程度**」に変わった。
正確さより、断定を避けるほうを優先する場面がある。

## 5. 揃えなくてよいもの（校正で「変更なし」とされた点）

こちらから統一を提案して、そのままでよいと判断された箇所。**今後は指摘しない。**

### 見出しの表記は揃えなくてよい

```
「距離感」という言葉の違和感          ← 「」の中は語だけ、句点なし
「馴れ馴れしさは、完了形で差し出される。」← 文まるごと、句点あり
```

同じ記事の中で混ざっていてよい。形式より、その見出しが指す中身の形に従う。

### 主語は省いてよい

```
こういうとき、たいてい「距離感がおかしい」と言われる。

壁をつくらないようにしている。
早く打ち解けようとしている。
場を和ませようとしている。
```

「その人は」を補わない。誰の話かは文脈で渡す。
補うと説明くさくなる。省いたほうが、読む側が自分の知っている誰かを当てはめられる。

## 6. 前置きを書かない

校正でいちばん大きく削られたのがここ。

削除された例:
- 「距離を詰めるのが異様に早い人が、どの職場にも大体ひとりはいる。」（総論）
- 「私自身、いくつかの業界を移ってきましたが……今回はそのことを書かせて頂きます。」（なぜ書くか）

**いきなり具体から入る。**

```
初対面でいきなり下の名前を呼ぶ。数回話したら急にタメ口。飲み会で肩を組んでくる。
```

※「正論」の記事では「なぜ書くか」を書いておられるので、
　自分が相談を受けた実績がある題材のときだけ入れる。ないなら書かない。

## 7. 出口セクションと締めは、記事によって出し分ける

| 記事の主題 | 出口（処方）| 締め |
|---|---|---|
| 読者が**消耗している**話（正論の記事） | **出す。**「一つ目は」「二つ目は」「三つ目は」で整理。三つ目は「離れてもいい」 | 「お役に立てたら嬉しいです」 |
| **概念を考える**話（親しみと馴れ馴れしさ） | **出さない。**校正で処方セクションは全削除された | 言い切って終わる |

毎回同じ型に押し込まない。

## 9. 公開版から分かったこと

### 「年齢や環境で、やりたいことをあきらめることはない」公開版から（2026/10）

下書きと公開版の差分から。**こちらが足した文は3つとも残り、そのうえで本人が中身を足した。**

### ① こちらの一般論には、本人が「理由」を足す

| 下書き | 公開版 |
|---|---|
| 途中で役割を変えてほしいと言うのは、勇気が要ります。 | 〜勇気が要ります。**わがままだと思われるかもしれない。今回は認められても次の業務が合わなかったらもう変えてくれとも言いづらい。** |
| 無料のものは、どこかで見直されます。 | **営利事業である限り、**無料のサービスはどこかで見直されます。 |
| 年齢や環境が関係ない、とは思いません。 | **新しい挑戦に**年齢や環境が関係ない、とは思いません。 |

一言で言い切る文は、本人の手で「なぜそう言えるか」「どの範囲の話か」が足される。
下書きでは、言い切りの直後に理由を書ける余白を残しておく。

### ② 他人の話は、伝聞で書く

「資格の勉強を始めました」→「始めて**いたそうです**」。
本人が見ていない他人の行動・気持ちは、「〜そうです」で書く。

### ③ 経緯のつなぎを足す

「この仕事に挑戦したい。」の前に「**レッスンを続けていく中で**」が足された。
出来事を並べただけだと、なぜそこに至ったかが飛ぶ。きっかけを一言でつなぐ。

### ④ 体言止めで終わらせず、動きまで書く

「年齢にも、環境にも関係なく。」→「〜関係なく**やりたい道を見つけ、進む。**」
「サポートしながら進める。」→「サポートしながら**いっしょに体を動かす。**」
締めの一文は、状態ではなく動きで終わらせる。

### ⑤ 表記

- 数字は算用数字: 一人 → **1人**、**1ヶ月**
- 応援する相手には「この人」より「**この方／その方**」（すべてではなく、混ざっていてよい）
- 「元同僚」→「同僚」。肩書きは簡単なほうを選ぶ

### ⑥ 使わなかったもの

- ★（当時の心の声）は使わなかった。**★は必須ではない**
- 見出しは、貼っていただいた本文には入っていなかった（短い記事では見出しなしもあり得る）

### 「組織あるある#2（ジョブ型）」公開版から（2026/10）

| 下書き | 公開版 | 分かったこと |
|---|---|---|
| 「うちはジョブ型です」／最近、よく聞くようになりました。 | **あなたの会社は本当にジョブ型ですか？** | 書き出しは、読者への問いかけもある |
| だから、誰かが拾うことになります。／ここが、いちばん厄介なところです。 | 誰かが拾うことになります。（メタ文は削除） | **「だから」「ここが厄介」のような、つなぎ・予告の文は要らない** |
| 私も、拾う側にいたことがあります。（こちらの推測） | 私も拾ったことがあります。**拾わないと現場が回らないからです。** | ★にも理由を添える（①と同じ） |
| それを知っておくだけでも、違うと思います。 | もし拾い続けて消耗しているのであれば／「それは私の仕事ではありません」／言ってみても良いかもしれません。／**言わないとしても、**その手札を持っておくだけで、違うと思います。 | **締めは、具体的な一手を渡し、そのうえで「しなくてもいい」逃げ道を残す。** タイトルの一言を締めで回収する |

タイトルは **問いかけ型＋末尾に「-組織あるある#N」**（「それは私の仕事ではありません」言えますか？-組織あるある#2）。

### 「距離の詰め方がうまい人」公開版から（2026/10・一部のみ受領）

| 確定稿 | 公開版 |
|---|---|
| パーソナルトレーナーの仕事の時の同僚に〜とよく言われ**ます**。 | パーソナルトレーナーの仕事を**していた際、**同僚に〜とよく言われ**ました**。 |
| その場所の基準をたまたま**身体で覚えていた**だけ | **自らの経験値から出るものが**その**環境**の基準をたまたま**満たした**だけ |

- 公開時にさらに直している。**本人が「これは自分の言葉だ」と挙げたのは、この書き直した一文だった**
- こちらの比喩（身体で覚えていた）より、本人の語（経験値）。比喩で飾らない
- 「場所」→「環境」（業界 → 環境 と同じ方向）

## やらないこと

- 常体か敬体かに統一する
- 前置き・総論から入る
- **経歴を前置きや裏付けに使う定型句**（「これまでの職場で見てきました」「いくつかの業界を移ってきましたが」）。本人は過去の仕事を聞かれない限り話さない（2026/10 一問一答 Q16）
- 例外を残さずに言い切る
- 相手を悪者にして終わる
- きれいごとだけで締める
- 自分を下げる言葉を使う
- 「いかがでしたか」「参考になれば幸いです」
- 裏取りしていない数字、確認していない実体験
- **こちらが解釈をまとめて書くこと（迷ったら空欄にして質問する）**
