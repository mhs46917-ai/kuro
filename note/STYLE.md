# 文体・トンマナ

> 目標とする書き方: 参考記事（「座る」をテーマにしたエッセイ）を分析して言語化したもの。
> 以降の記事はすべてこのルールで書く。

## 基本設定

| 項目 | 設定 |
|---|---|
| 一人称 | 僕 ※要確認。自己紹介記事では一人称をほぼ省略されているので、「私」がよければ一括変更します |
| 文体 | です・ます調 |
| 読者への呼びかけ | 本文中は使わない。最後の締めでだけ「あなた」を出す |
| 絵文字 | 使わない |
| 顔文字 | `(笑)` のみ。半角カッコ。1記事に1〜2回まで |
| 体言止め | ほぼ使わない |
| 箇条書き記号 | 使わない。短文の改行で代用する |

## この文体の核

### 1. 1行1文。改行が段落をつくる

段落を組まない。1文書いたら改行する。関連する2〜4文をまとめたら空行を入れる。

```
別に深い話をするわけではありません。
何も話さない人もいる。
火をいじっている人もいる。
```

箇条書き（`-`）にはしない。改行の連打そのものがリズムになる。

### 2. 文末を「て」で止めて、言い切らない

- 「〜と思ってて。」
- 「〜機会があって。」
- 「〜が気になっています。」

断定を避ける語尾を意図的に使う。これが語りかけの温度をつくっている。
ただし多用しすぎると弱くなるので、1記事に4〜6回。

### 3. 自信のなさを隠さない

- 「自分でもどこまで分かって書いていたのか、怪しいものです」
- 「〜なのかもしれません」
- 「いまは少しだけ続きを言える気がします」

結論を持っている人ではなく、考えている途中の人として書く。
**これがこの文体のいちばんの特徴。** 整理して教える文章にした瞬間、別物になる。

### 4. 見出しは「」でくくった断片フレーズ

説明的な見出しにしない。本文から抜き出した一言を「」に入れる。

| ダメな見出し | この文体の見出し |
|---|---|
| 座ることの重要性について | 「席にはいる。でも、座っていない。」 |
| 役割と本音の関係 | 「役割を脱がなくていい。」 |
| 心理的な抵抗 | 「座るのは、案外怖い。」 |

句点（。）を見出しの中に入れる。2文に割ってもいい。

### 5. 定義は否定から積む

```
信頼とは、相手が自分を裏切らないと確信することではない。
同じ価値観になることでもない。

互いに影響を受けることを、完全には拒まないこと。
```

「〜ではない。〜でもない。むしろ〜」。
肯定形の定義をいきなり出さず、削っていった先に置く。

### 6. 命名するが、断定しない

- 「僕は、それを『理解』と呼びたいのかもしれません」
- 「信頼と呼んでもいいのではないか、と」

抽象語を自分の言葉で定義し直す。ただし「〜である」と確定させず、
「呼びたい」「呼んでもいい」と留保をつける。

### 7. 具体を畳みかけて、読者に自分の場面を思い出させる

```
社長である。
父親である。
上司である。
部下である。
先生である。
```

```
「あの人は主体性がない」
「最近の若手は」
「経営者だから仕方がない」
```

3〜5行。説明しない。並べるだけで、読者が自分の記憶を当てはめる。

### 8. キーワードは1語に絞り、執拗に繰り返す

参考記事は「座る」だけで最後まで通している。
他の言葉に言い換えない。同じ語を何十回も出す。

### 9. 結論を出さず、問いを渡して終わる

最後は短文を改行で連打して速度を上げ、問いかけで止める。

```
だから、まず座る。

何かを解決する前に。

分かり合おうとする前に。

何者かになろうとする前に。
```

そして「あなたは、どう思いますか？」。
まとめない。「いかがでしたか」は絶対に書かない。

## 発信テーマと読者

詳細は `note/PROFILE.md`。

テーマ: **「どこでも通用するスキル」「通用しない価値観」**を実体験ベースで。
読者: 異業種転職を考えている人／現場で試行錯誤している人／これから店舗運営・マネジメントに携わる人。

この文体（結論を出さない思索型）と、この発信テーマ（実体験ベースの実用情報）は、
放っておくと引っ張り合います。両立させる型はひとつ:

**抽象的な問いから入らず、業界を移ったときに通用しなくなった具体から入る。**
そこから考え始めれば、思索の文体のまま、読者の実務に刺さります。
参考記事も、焚火という具体から入って最後は組織の話に降りていました。同じ構造です。

## 記事の規模

- 本文 5,000〜6,000字。この文体は改行が多いので、字数のわりに読むのは速い。
- 見出し（h2）は 6〜9本。1セクションが短い。
- 1セクション 400〜800字。

## 構成の型（参考記事の骨格）

| # | ブロック |
|---|---|
| 1 | 「最近◯◯のことをよく考えてる」＋ 誤解の先回り否定 `(笑)` |
| 2 | 具体的な場面。自分が実際に見たもの |
| 3 | 「これは何なんだろう」という問い |
| 4 | 自分なりの言い換え・命名 |
| 5 | 反対側の事例（そうでないほうの例） |
| 6 | 中心概念の再定義 |
| 7 | 怖さ・抵抗を認める |
| 8 | 予想される反論への応答 |
| 9 | 仕事・組織の話への接続 |
| 10 | 短文連打 → 問いかけ → 読者への呼びかけ |

## やらないこと

- まとめの箇条書き（「ポイントは3つです」）
- 「いかがでしたか」「参考になれば幸いです」
- 教える口調（「〜しましょう」「〜すべきです」）
- 絵文字、太字の多用、装飾
- 裏取りしていない数字
- **参考記事の筆者の固有名詞・経歴を借りること**（焚火・仙台・100人会議・SBC など）。
  文体は目標にしてよいが、経験は自分のものを入れる
