# 文体・トンマナ

素材: ご本人の3本（自己紹介 / 正論の記事 / 「親しみと馴れ馴れしさ」校正版）。
校正で入った直しから、好みをかなり正確に拾えたのでそれを反映している。

---

## 基本設定

| 項目 | 設定 |
|---|---|
| 一人称 | **私**。使う回数は少なめ。省けるところは省く |
| 文体 | **常体と敬体の混在**（下記） |
| 絵文字・顔文字 | 使わない |
| ダッシュ | `──` を使う。三点リーダーは使わない |
| 分量 | **2,300〜3,000字** |
| 見出し | 6〜8本。**「」で全部くくり、句点で閉じる** |

---

## 1. 常体と敬体の混在

最大の特徴。無意識に使い分けておられます。**どちらかに統一すると別人の文章になる。**

| 内容 | 文体 | 例 |
|---|---|---|
| 一般化した観察・分析・断定 | **常体** | 「近さの量では、説明がつかないのだ。」「遠いのではなく、動かない。」 |
| 自分の経験・読者への語りかけ | **敬体** | 「転職する度に思うことがあります。」「踏み込んでいいと思います。」 |

分析で常体に落ち、自分の話に戻るとき敬体に上がる。この上下動が信用をつくっている。

---

## 2. 改行を多くとる。1行1文に寄せる

**※ここは以前の指示が間違っていたので訂正。** 校正で改行が大幅に増やされました。

- 列挙、畳みかけ、短い断定 → **1行1文**

```
ずっと敬語のまま。
当たり障りのないことしか言わない。
相手の話を、否定も肯定もせずに受け流す。
役割としてだけやりとりする。
```

- 説明が続く箇所だけ、2〜3文をまとめる
- 箇条書き記号（`-`）は使わない。改行そのものがリズム

---

## 3. 誠実感の正体

いい言葉を選んでいるからではなく、次の5つを毎回やっているから。
**特に1つ目が核。** 校正で入った直しは、ほとんどがこれでした。

### ① 言い切ったあと、必ず例外を残す

| 校正前 | 校正後 |
|---|---|
| 24時間ジムに来られる方の**多くは** | 24時間ジムに来られる方は**様々でしたが、多くは、** |
| その場所の基準をたまたま身体で覚えていただけ | 〜覚えていただけ、**またはフィーリングが合う相手なだけ** |
| 正直に言うと、私自身もやってきた側です | **シチュエーション次第で**私自身もやってきた側です |

**過度な一般化をしない。** 断定はする。したうえで、当てはまらない場合を1つ残す。
これが「この人は現場を見てきた人だ」という信頼をつくっている。

### ② 相手を悪者にしない

批判対象にも、まず善意を認める。「善意なのだ。善意なのだが、一方通行。」

### ③ きれいごとで終わらせない

模範解答のあとに、自分の実際の振る舞いを足す。
「私はあまりに酷い際は時々無視します。」「親しみのつもりで、逃げ場をなくしていました。」

### ④ 自己卑下の語は使わない

校正で **臆病 → 繊細** に直されました。
正直に書くが、自分を下げる言葉は選ばない。

### ⑤ 硬い語を避ける

校正で入った言い換え: **業界 → 環境** ／ **非対称 → 構図**
専門用語で決めない。日常の語で言う。

---

## 4. 前置きを書かない

校正でいちばん大きく削られたのがここ。

削除された例:
- 「距離を詰めるのが異様に早い人が、どの職場にも大体ひとりはいる。」（総論）
- 「私自身、いくつかの業界を移ってきましたが……今回はそのことを書かせて頂きます。」（なぜ書くか）

**いきなり具体から入る。**

```
初対面でいきなり下の名前を呼ぶ。数回話したら急にタメ口。飲み会で肩を組んでくる。
```

※「正論」の記事では「なぜ書くか」を書いておられるので、
　自分が相談を受けた実績がある題材のときだけ入れる。ないなら書かない。

---

## 5. 出口セクションと締めは、記事によって出し分ける

| 記事の主題 | 出口（処方）| 締め |
|---|---|---|
| 読者が**消耗している**話（正論の記事） | **出す。**「一つ目は」「二つ目は」「三つ目は」で整理。三つ目は「離れてもいい」 | 「お役に立てたら嬉しいです」 |
| **概念を考える**話（親しみと馴れ馴れしさ） | **出さない。**校正で処方セクションは全削除された | 言い切って終わる |

毎回同じ型に押し込まない。

## 6. 参考記事（「座る」）から借りるもの・借りないもの

| | 借りる | 借りない |
|---|---|---|
| 見出し | 「」でくくった断片フレーズ | — |
| リズム | 1行1文の畳みかけ | — |
| 定義 | 否定から積む（「〜ではない。〜でもない。むしろ〜」） | — |
| 一人称 | — | 「僕」 |
| 結論 | — | 結論を出さずに問いだけで終わること |
| 素材 | — | 焚火・仙台・100人会議・SBC などこの筆者の経歴 |

## 発信テーマと読者

詳細は `note/PROFILE.md`。

テーマ: **「どこでも通用するスキル」「通用しない価値観」**を実体験ベースで。
読者: 転職を考えている人／現場で試行錯誤している人／店舗運営・マネジメントに携わる人。

強みは、**同じ行為の意味が環境をまたぐと反転する現場を何度も見ていること**。
抽象的な問いからではなく、環境を移って通用しなくなった具体から入る。

---

## やらないこと

- 常体か敬体かに統一する
- 前置き・総論から入る
- 例外を残さずに言い切る
- 相手を悪者にして終わる
- きれいごとだけで締める
- 自分を下げる言葉を使う
- 「いかがでしたか」「参考になれば幸いです」
- 裏取りしていない数字、確認していない実体験
