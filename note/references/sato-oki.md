## 口調の仕組み（読み取り）

1. **抽象を、身近な人や物に置き換える。**「伝わるデザイン」→「オカンに電話で伝わる」
2. **常識を逆から言う。**「面倒臭いほうを選ぶ」「センスではなく努力」「ウラからのぞけばオモテが見える」
3. **言い切りを「〜気がします」でやわらげる。** 断定の強さはあるが、押しつけない
4. **自分を少しだけ茶化す（脱力）。**「言い訳っぽいですかね」。偉そうにならない
5. **決めごとは数字で言う。**「1年で解散」
6. **楽しんでいる感じが出ている。**「純粋に楽しもうよ」「面白がる」
7. 基本は です・ます の話し言葉。語りかける

## 足りないもの＝「温度感」の正体（こちらの仮説）

こちらの下書きが冷たく見える理由:

- **全文が同じ温度の断定**（〜です。〜ではない。〜です。）。気持ちの語尾（〜気がします／〜なんですよね）がない
- **抽象のまま**。身近な人・物への置き換えがない（佐藤さんの「オカン」にあたるもの）
- **1行1文で細切れにしすぎ**。公開版では、つながる文を本人がつないでいた（STYLE.md 2）
- 楽しんでいる／面白がっている気配がない。正しさだけで書いている

## 借りないもの

- **「（笑）」や冗談の量。** 本人は「思わず笑うことはない」（Q2）。軽さは「助かった」型の乾いた一言まで
- **自分を下げる茶化し。** STYLE.md ⑤ 自己卑下の語は使わない
- **デザインの専門語**

貼ってもらったのは、(1) イルミネーションを見て「なぜきれいと思うのか」を考えてしまう話、(2) ニュートラルでいることと、勝負の場では負けない意思の話、(3) 毎日同じ服・同じそば・同じ散歩コースで調子を保ち、来た仕事は全部好きになる話。

### 温度をつくっている仕組み

| 仕組み | 例（短い断片） | 本人の記事での使い方 |
|---|---|---|
| **語尾の種類が多い** | 〜かもしれません／〜なのかなって思っています／〜じゃないでしょうか／〜てほしいと思います／〜と思っています | 同じ語尾を3回続けない。断定・推量・語りかけ・願いを混ぜる |
| **話し言葉を少し崩す** | 「付いちゃう」「ずーっと考えちゃう」「〜って」 | 1記事に1〜2か所だけ。自分の癖を語るところで使う |
| **日常の、少し意外な具体例** | イルミネーション、マグロ漁 | 抽象を言ったら、すぐ誰でも見たことのある場面に落とす。少しずれた例ほど温度が出る |
| **他人の声を「」で入れる** | 「わーきれい！」／純粋に楽しもうよって（笑） | 周りの反応を一言で入れると、場面が立つ（VOICE.md 9 と同じ） |
| **自分の見方の癖から語る** | なぜきれいと思うのかを考えてしまう | 「〜してしまう」と自分の癖を出し、それが仕事の原理につながる。**本人の Q11（先回りしてリスクを潰す）と同じ形** |
| **逆から見る** | どうしたらきれいじゃないイルミネーションになるのか | 本人の「正体は〜ではなく」と同じ。すでに持っている |
| **二重否定でニュアンスを出す** | 「できる」確信はないけど、「できない」とも思わない | 白黒つけない気持ちを、両方否定で言う |
| **「とはいえ」で反対側も言う** | とはいえ、勝負の場面では負けないという意思も大切 | STYLE.md ①（例外を残す）と同じ。すでに持っている |
| **ありふれた言葉を自分で定義する** | 僕にとって「負け」とは、人の期待に応えられないこと | 「私にとって〜とは」。記事の核になりやすい |
| **弱みを事実で言い、短い決意で返す** | 〜教わったわけでもなければ、〜ノウハウもありません。→ だからこそ〜。それは今も変わりません。 | 自己卑下ではなく事実。最後は短く言い切る |
| **比喩を一つ決めたら通す** | ホームラン → バットを振り続ける | 比喩は1記事1つ。出したら最後まで同じ比喩で |
| **具体を3つ並べる** | 同じシャツ、同じそば、同じ散歩コース | 本人の「理由は3つ」の癖と相性がよい |
| **長めの文をつなぐ** | 例えば、〜ときに、〜と言っているときに、〜を考えてしまう。 | 1行1文で切りすぎない。つながる文はつなぐ（STYLE.md 2） |

### 本人の文章との距離

- **もう持っている:** 逆から見る、例外を残す、自分の癖を語る（Q11・Q13）、3つ並べる、数字で決める
- **足りない（＝温度）:** 語尾の種類、話し言葉の崩し、日常の意外な具体例、比喩を通すこと
- **借りない:** （笑）の多用、自分を「バカ」など下げる語（STYLE.md ⑤）、佐藤さん固有の言葉
