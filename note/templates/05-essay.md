# 標準の型（ご本人の文体 8 ／ 参考記事 2）

`note/STYLE.md` とセットで使う。指定がなければこの型で書く。

---

## 書ける／書けないの見分け

書けるテーマ:
- 職場で実際に見た、噛み合わなさがある
- 業界を移ったときに、通用しなくなったものがある
- 消耗している人に、渡せる出口がある

書けないテーマ:
- 場面が思い出せない
- 出口がない（読者を追い詰めるだけになる）

---

## 骨格

```markdown
（いきなり具体の場面から。総論・前置きは書かない）
（※「なぜ自分が書くのか」は、実際に相談を受けた題材のときだけ入れる）

## 「悪気がない。だから、こじれる。」
★必ず入れる。相手を悪者にしない。善意であることを先に認める
★受け取る側にも事情がある、と両方をフォローする

## 「『◯◯』という言葉では、片づかない。」
世間の説明を出し、それでは足りないと言う

## 「（自分の言い換え）」
中心概念を、否定を積んで定義し直す

## 「業界が変わると、正解も入れ替わる。」
★この人だけの切り口。デザイン／ジム／営業／福祉／設備管理から2〜3つ
★ここだけ敬体が増える（自分の経験だから）

## 「（反対に見えるもの）も、根は同じだ。」
転回を置く

## 「（結論にあたる一言）」

## 「（自分もやっていた、という告白）」
★きれいごとで終わらせないための必須セクション
★格好悪いことを、格好つけずに書く

## 「受け取る側が、抱え込まなくていい。」
※読者が消耗している話のときだけ入れる。概念を考える話では入れない
★出口を三つ。「一つ目は」「二つ目は」「三つ目は」で整理する
★三つ目は「離れてもいい」。ただし一時の感情ではない、と添える

## 「それでも、◯◯していい。」
否定で終わらせず、ひっくり返す

（締めは記事による。消耗の話なら「お役に立てたら嬉しいです」、
　概念の話なら言い切って終わる）
```

## チェック

- [ ] 常体と敬体が混ざっているか（どちらかに統一していないか）
- [ ] 分析は常体、自分の経験と読者への語りかけは敬体になっているか
- [ ] 一人称が「私」か
- [ ] 「──」を使っているか
- [ ] 相手を悪者にせず、善意であることを先に認めたか
- [ ] 自分の格好悪い部分が最低1つ入っているか
- [ ] 読者に出口を渡したか（三つの処方）
- [ ] 見出しが「」の断片フレーズになっているか
- [ ] 改行を十分にとったか（列挙・畳みかけは1行1文）
- [ ] 前置き・総論から入っていないか（いきなり具体から）
- [ ] 言い切ったあと、例外を1つ残したか
- [ ] 自分を下げる言葉を使っていないか
- [ ] 硬い語を日常の語に言い換えたか
- [ ] 2,300〜3,000字に収まっているか
- [ ] 「いかがでしたか」を書いていないか
