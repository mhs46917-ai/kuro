# 短編の型（組織あるある観察記）

1,000〜1,500字。軽く、速く、数を出す。長編とは進め方を変える。

---

## 進め方（長編との違い）

| | 長編（職歴シリーズ） | **短編** |
|---|---|---|
| 素材集め | 何往復もヒアリング | **質問は多くて1つ** |
| 下書き | 素材が揃ってから | **先に最後まで書く** |
| 本人の作業 | 全面的に加筆 | **★1か所に自分の一言を足す** |
| 字数 | 1,800〜2,100字 | **1,000〜1,500字** |
| 見出し | 6〜8本 | **3〜5本** |

**最初に「言いたい一文」を決める。** 本人は記事を、言いたい一文から考え始める（2026/10 一問一答 Q17）。
素材にあればそれを使い、なければ「質問は1つ」をこれに使う。
その一文は、**タイトルと締めの両方**に置く（#2 公開版:「それは私の仕事ではありません」）。

**一般的な観察だけで骨格が立つのが短編の利点。**
こちらで書き切って、本人しか書けない一言だけ空けておく。

---

## タイトル

**末尾に「-組織あるある#N」を付ける。** #2は問いかけ型にしている。
例: 「それは私の仕事ではありません」言えますか？-組織あるある#2

---

## 骨格

**基準の記事: #3「中間管理職は、本当に板挟みですか？」温度版（`note/articles/aruaru/03-chukan.md`）。** 本人が「今後の記事はこの書き方をベースに」と決めた（2026/10/7）。迷ったらこの記事を開いて合わせる。

```markdown
（読者への問いかけ。よく聞く言葉を疑問の形で）
（よく言われる中身を一文で。「〜とよく言われますよね」）
（でも、少し違った気がする。言いたい一文の予告）
※ 経歴を前置きにしない。「どの職場でも聞いた」「これまで見てきた」は使わない

## 「（違和感の言語化）」
なぜ違うのか。理屈をひとつだけ

## 「（言いたい一文の核）」
**みんなにわかる例えを1つ**（八百屋さんの「今日はこれが旬ですよ」のような、誰でも見たことのある場面）
→「私にとって〜とは」で言葉を定義し直す
→ 言いたい一文を、ここで一度言う

## 「（とはいえ、の節）」
例えが当てはまらないところ。例外を残す。ここに ★スロット（場面＋いまどう思うか）

## 「（捉え直すと、どう楽になるか）」
相手を悪者にしない。人格の話を、別の話に戻す

## （締め）
「〜な人へ」で始める
→ 力不足ではない、と渡す
→ 例えの続きで一手を1つ（「商品を変えて、また明日持っていけばいい」）
→ しなくてもいい、と逃げ道
→ 応援で終える
```

### 温度のルール（詳細は `note/references/sato-oki.md`）

- **例えは1記事1つ。出したら締めまで同じ例えで通す**（#3: 売りに行く → お客様 → 取引先 → 提案 → 商品）
- **例えは、本人の素材や言葉の中から探す**（#5: 部活 → ヒーローインタビュー／「あきらめない」: 本人の「やりたい道」→ 道）。こちらが外から持ってきた例え（電車の乗り換え）は「分かりにくい」と言われた
- 語尾を混ぜる（〜でしょうか／〜ますよね／〜気がします／〜じゃないでしょうか／〜かもしれません）。同じ語尾を3回続けない
- 話し言葉の崩し（〜ちゃう、〜って）は1〜2か所まで
- つながる文はつなぐ。1行1文で切りすぎない
