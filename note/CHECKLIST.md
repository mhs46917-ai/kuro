# 公開前チェックリスト

## 中身

- [ ] タイトルと本文の結論が一致している
- [ ] リードに「この記事で何がわかるか」が書いてある
- [ ] 各見出しに具体例（数字・固有名詞・実体験）が最低1つある
- [ ] 具体例が書けなかった見出しは削ったか、書き足したか
- [ ] 引用・数字に出典がある
- [ ] 他人・他社が特定できる書き方になっていないか

## 読みやすさ

- [ ] 60字を超える文を切った
- [ ] 3〜5行ごとに空行が入っている
- [ ] 同じ文末（〜ます。〜ます。〜ます。）が3回続いていない
- [ ] 「思います」「かもしれません」が合計3回以内
- [ ] 音読して詰まるところがない

## note側の設定

- [ ] 見出しは「見出し」機能で設定（太字だけにしていない → 目次に出ない）
- [ ] 見出し画像を設定した
- [ ] ハッシュタグ 3〜5個
- [ ] 有料設定・マガジン追加の要否を確認
- [ ] スマホプレビューで1画面ぶん読んでみた
