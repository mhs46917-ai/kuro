# 話し方の素材置き場

ここに置いたものを読んで、`note/VOICE.md` を更新する。

## いちばん効く素材: 音声入力の文字起こし

スマホの音声入力（キーボードのマイク）で、下のどれかに **3分くらい** しゃべって、そのまま貼る。
言い直し・「えーと」・誤変換も直さずにそのままでよい（むしろそれが欲しい）。

### しゃべるお題（どれか1つでOK）

1. 20代後半、何に怒っていたか（「モチベーション」記事の素材にもなる）
2. いちばん笑った職場の出来事
3. 最近いらっとしたこと、それをどう流したか
4. 誰かに仕事のことで相談されて、何と返したか
5. いまの仕事で、楽しいと思う瞬間

## そのほか使えるもの

- X の投稿（自分で書いたもの）
- 普段のメッセージで、自分の言葉らしいと思うもの（相手の名前は消す）
- 公開した記事の本文（下書きとの差分は STYLE.md に入れる）

## ファイル名

`YYYY-MM-DD-お題.txt`（例: `2026-10-08-怒り.txt`）
チャットに直接貼ってもらえれば、こちらで保存する。
