# 話し方・考え方の癖

`STYLE.md` が「仕上げた文章」の分析なのに対し、こちらは**構えずに出てくる言葉**の分析。
記事の骨組み・★スロット・ヒアリングの聞き方・X投稿文に使う。

素材: このリポジトリでのやりとり92件（2026/9〜10）。
とくに職歴シリーズのヒアリングへの回答（質問に答えながら当時を思い出している文）。
**※チャットに打った文であって、声で話した言葉ではない。** 音声の文字起こしが入ったら更新する（`note/samples/`）。

---

## 1. 感情は、両方並べる

一つの感情に寄せず、反対側の気持ちを「同じくらい」で並べる。STYLE.md の「誇らしい、ただモヤモヤが残る」と同じ形。

```
責任を感じておかしくなったのかももちろんあった。
→それと同じ位本音で、最初に上手くいかない可能性は覚悟してなかったのか？
```

```
地道に今は多くの人に配るしかない、反対に何やっているんだ、という気持ちもありました。
```

→ 下書きで「前向きな気持ち」だけを書かない。**反対側の気持ちが聞けていなければ、そこを質問する。**

## 2. 他人の内心は、決めつけずに2つ並べる

```
本人も薄々気づいていたのか、こちらに気を使ったのか、はい、わかりましたといつもの元気さで返事をした。
```

```
自分の知らない所で色々言われていたのか、言われてなくても責任を感じておかしくなったのか
```

→ 他人の気持ちを書くときは「〜なのか、〜なのか」で2つ置き、どちらとも言わない。公開版で入った伝聞「〜そうです」と同じ姿勢。

## 3. 相手の判断にも、まず理屈を認める

```
理屈はわかるが実績がなく赤字を出していた店だったので当然だったと思います。
```

不利な判断をされた場面でも、先に相手側の筋を通す。STYLE.md「相手を悪者にしない」の出どころはここ。

## 4. 着地は「恨みはない」「自分で選んだ」

```
最後は良い結果ではなかったですが彼が声を掛けてくれたことで自分の人生の転機になったと思います。
その後は自分で選んだ道なので恨みもないです。
```

→ 苦い話の締めは、相手への感謝と自分の選択で着地する。**被害者の位置に立たない。**

## 5. 自分の功績は小さく言う。ただし理由つきで

```
私の功績は自分達でピンチを作り、それを回復しただけ、予定通りの数字を出している人たちとは比べられるのも申し訳ない
```

```
ノミネートにはいれたのも会議で誰かが名前を出してくれ、評価してくれているから、その人達の顔をたてる為に参加するか
```

謙遜はするが、自己卑下ではない（STYLE.md ⑤）。**小さく言う理由を、論理で説明する。**
そして動く理由は「誰かの顔を立てる」「周りへの配慮」になりやすい。

## 6. 決断は、損得とリスクで説明する

```
自社内の異動で現場の経験が積め転職よりリスクが低い
```

```
私でなくても問題なく返済可能でしたので退職しました。
```

情熱より、**比べたうえでの合理的な判断**として語る。
「チーム」の記事で「ビジネスは損得が絡む」を前提に置いたのも同じ軸。

## 7. 喜びは「誰かに届いた」ときに出る

```
当時好調だが1人で働いていて孤独感もあった中、自身の行動が同じ会社とはいえ離れた土地のあったことないアルバイトに響いていて行動を起こすきっかけになれていたのは嬉しかったです。
```

数字の達成より、**自分の行動が他人の行動を変えた**ことを喜ぶ。PROFILE.md の総括「人を支える仕事」と一致する。
弱さ（孤独感）は、喜びの前置きとして短く正直に出す。

## 8. 苦労は、淡々と事実で言う

```
病院にいってません、行く時間も取れない状態でした
```

```
1日600件〜1000件、営業時間の空き時間に
```

形容詞で盛らない。**数字と事実だけ置く。** 数字はよく覚えている（会員数・単価・件数・月数）。
→ 下書きで「必死に」「懸命に」を足さない。数字を聞く。

## 9. 人の言葉は、そのまま鍵括弧で残す

```
「店長大丈夫ですか？」
「ノースタッフデー作って良いから休め」
「半年チャンスを下さい。6ヶ月後にまだ赤字だった場合差額をここにいる6名の給与から補填する」
```

自分の心の声も同じ。

```
「あ、聞いていた数字と違う。増えた。」と冷静でした。
```

→ 心の声を鍵括弧で置いたあと、**自分の状態を一語で添える**（冷静でした）。ヒアリングの答えに出てきた鍵括弧は、記事にそのまま使う。

## 10. 理由は番号で並べる

```
理由1)基本的に会社や上司など上位職が使用することが多い
理由2)コロナ期が印象的だが〜
理由3)チームという言葉を使う人程〜
```

頭の中で理由を3つに分けて持っている。ヒアリングの答えも、理由が3〜4つ並ぶことが多い。
→ 短編の骨組みは、いただいた番号の順にそのまま見出しにしてよい。

## 11. 問いは、問いのまま置く

```
「日本的な考え方？」
```

分からないことは、断定せずに疑問で置く。下書きでも「〜なのかもしれません」で止める。

## 12. 列挙は読点で畳みかけ、「等」で閉じる

```
流行への関心の低下、現場のモチベーションが低くマンネリ化、誰よりも成果を出しても年功序列、上手くいっていないと感じたデザインでも私の作品だからと通ってしまう等。
```

記事では1行1文に分けるが、**並べる項目と順番は、この並びを尊重する。**

## 13. 体感のある言葉を選ぶ

「萎える」「魅せる」「拾う」「執念」「覚悟」「熱さ」
硬い概念語（モチベーション低下、エンゲージメント）ではなく、身体でわかる言葉を選ぶ。
→ いただいた言葉を、こちらで一般的な言葉に言い換えない（「萎え」を「意欲低下」にしない）。

## 14. 敬語とくだけた言葉が混ざる

チャットでは「ありがとう」「〜もらえる？」「〜で」と、「〜下さい」「〜させて頂きます」が混ざる。
**記事の常体／敬体の混在（STYLE.md 1）と、同じ動きが会話でも起きている。** 統一しない理由の裏付け。

## アンケートの結果（2026/10/7・選択式12問）

本人に、同じ内容を書き方だけ変えた例文から選んでもらった結果。**上の分析より、こちらを優先する。**

| 項目 | 選んだもの | 書くときの扱い |
|---|---|---|
| 書き出し | **読者への問いかけ** | 「あなたの職場に〜は本当にありますか？」の形を第一候補にする |
| 言い切りの語尾 | **場面で使い分ける** | 「〜だと思います／〜です／〜かもしれません」を内容で選ぶ。どれかに揃えない |
| 読者への呼びかけ | **「〜な人へ」** | 「あなた」で直接指すより、当てはまる人に向ける形を優先 |
| 批判の温度 | **やわらかく言う** | 「少しだけ、違和感がありました」くらい。強い否定語は使わない |
| 締め | **応援・感謝で終わる** | 「〜な人へ」＋応援、の形が基本。#2公開版の「一手＋逃げ道」と組み合わせてよい |
| 失敗・しんどさ | **今の意味づけまで書く** | 事実 → 今どう思うか、まで。**ただし意味づけは本人が書く。こちらは★で空けて聞く**（STYLE.md 4） |
| 軽さ・笑い | **たまに一行だけ** | 真面目な流れの中に、力を抜く一文を1本まで |
| カタカナ語 | **一般的なものだけ** | モチベーション・マネジメントは可。エンゲージメント等は日常語に言い換える |
| タイトル | **問いかけ** | 第一候補を問いかけ型にする。短編は末尾に「-組織あるある#N」 |
| 経歴の出し方 | **あまり出さない** | 観察と考えが中心。経歴は説得力に必要な一言だけ。自己紹介や職歴の繰り返しはしない |
| 届けたい読者 | **現場で消耗している人／上司・管理職** | 両方に届く書き方を基本に。どちらかに寄せる回は申し送りに書く |
| 書く理由 | **誰かの役に立ちたい／収益にしたい** | 役に立つ出口（応援・一手）を必ず置く。有料化の判断は MONETIZATION.md |

## 一問一答から分かったこと（2026/10/7・自由記述）

回答の原文は `note/samples/2026-10-07-qa.md`。

| 分かったこと | 回答の例 | 書くときの扱い |
|---|---|---|
| 不満は、結果だけ置いて終える | 「〜キャンセルの電話が来て助かった。」 | 怒りを説明しない。乾いた一言で締めるのが本人の「軽さ」 |
| 笑いの話は出てこない | 「基本的に思わず笑うことないかも。」 | **冗談を作って入れない** |
| 怒りの向き先は、人 → 仕組み → 自分 | 「仕組みを変えられない立場や思考ができない自身にも怒りがあった」 | 最後は自分に向ける。他人を悪者にして終えない |
| 許せないのは「無責任・安易な口出し」 | 「無責任や安易な助言に対しては反論や改善策を提示するタイプ」 | 書き方はやわらかいが、線引きははっきりしている。**怒りは提案に変える** |
| 他人への違和感は「自分にはそう見える」 | 「楽しそうに過ごせてない気がする」「言い訳に聞こえてしまう」 | 「〜気がする」「〜聞こえてしまう」で書く。相手を断じない |
| 迷いながら、仮の答えは自分で出す | 「迷ってます。」→「結局私の人生なので自分のために働いていると思います。」 | 迷いを正直に置き、最後に本人の仮の答えを置く。**答えはこちらが作らない** |
| 先が見えると面白くない | 「その先数年が見えてしまうと面白くないと思ってしまいます」 | 経歴が多業種である理由。経歴を出すときの軸になる |
| 自分の傾向は「〜てしまう」で認める | 「思ってしまいます」「なってしまっているかもしれないです」 | 少し引いて認める。自己卑下の語にはしない |
| 喜びは、誰かに届いたとき | 嬉しかった一言＝北海道の社員からのメール（Q7） | 7 の裏付け。ただし同じ話は職歴 Part 5 で使用済み |
| 教えるときは「負担を下ろす → 1つ頼む → 1つだけ禁止」 | 「全部覚えてなんて無理なことは言わない。〜都度質問して欲しい。一番良くないのはその場しのぎで〜」（Q8） | **記事の処方もこの順で書く。** 禁止は最後に1つだけ、「一番良くないのは」で |
| 尊敬の基準は「感謝・固定しない・責任」 | 尊敬できないのは「感謝ができない／自分のやり方しか正解としない／立場や責任にあった振る舞いができない」（Q9） | **Q4・Q6・Q8 と一本でつながる価値観の軸。** 記事の批判はこの3つのどれかに当たる |
| 嫌いな人にも「方」 | 「〜な方」「どんな方でも尊敬する部分はあった」（Q9） | 批判対象にも敬称と例外を残す |
| 反論は「一度受け取ってから」 | 「それも選択肢として考えてはいたのですが」（Q10） | 記事で否定するときも、相手の案を一度認めてから「ただ」で返す |
| 見え方と本音のずれを、軽く明かす | 「落ち着いている人」と言われるが「リスクが見えたら事前に手を打っておきたいだけ」→「伝わって無くて助かってます」（Q11） | 本音は正直に、ただし重くしない。**「助かった」で着地するのが本人の軽さの型**（Q1と同じ） |
| 強い本音の前にクッション、後に感謝 | 「言い方が悪いですが上司や社長でも会社が変われば他人」→「それでも〜誘ってくれる方々は感謝しかないです」（Q12） | ドライな本音を書くときは、前に「言い方が悪いですが」、後に感謝。**本音だけで終えない** |
| 自分らしさは「自分で時間配分できること」 | 「内容は関係なく誰かのペースや都合に時間をとられることなく〜」（Q13） | 喜び（誰かに届いた）とは別軸。**他人のペースに時間を取られる話**は、本人の実感がこもるテーマ |
| 消耗するのは「自分の言葉でない言葉」 | 「決まりごとの説明など自分の言葉でなく話すことです」（Q14） | **こちらが足した一般論・解釈は、本人にとって「自分の言葉でない言葉」。** 下書きでは借り物の言い回しを減らし、いただいた言葉を残す（STYLE.md 4 の裏付け） |
| 「自分の言葉」と感じる文 | 「上手さの正体は技術ではなく、自らの経験値から出るものがその環境の基準をたまたま満たしただけ〜」「持ち場が変われば、通用しない。」（Q15） | **本人が書き直した箇所だった。** 褒め言葉を「たまたま」「だけ」で相対化 → 否定してから定義 → 短い断定で切る、の流れ |
| チャットの素の語尾 | 「〜かな」「〜かも」「〜と思う」 | 記事には出さないが、X投稿文なら少し使える |

## 記事づくりでの使い方

| 場面 | やること |
|---|---|
| ヒアリング | 気持ちを聞いたら、**反対側の気持ちもあったか**を聞く（1）。数字を聞く（8） |
| 他人が出てくる | 内心は2つ並べるか伝聞で（2）。相手の判断の理屈を先に書く（3） |
| 苦い話の締め | 恨みではなく、感謝か自分の選択で着地（4） |
| 自分の成果 | 小さく言う理由を書く。盛らない（5・8） |
| 素材の言葉 | 鍵括弧・体感語・番号の順は、そのまま使う（9・10・13） |
| 締め | 誰かに届いた、誰かが動いた、で終えると本人らしい（7） |

## まだ足りない素材

- **声で話した言葉**（音声入力の文字起こし）。チャットより口癖・語尾・間が出る
- 怒っているときの言葉（「モチベーション」記事の20代後半＝怒り、で必要になる）
- 笑い話・軽い話（いまの素材は真剣な話に偏っている）

集め方は `note/samples/README.md`。
