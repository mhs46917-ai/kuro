# 記事間リンクの貼り方と、貼るテキスト

流入の89%がnote内。**内部導線が生命線**なので、ここを整える。

---

## 貼り方（3種類）

### 1. 埋め込みカード ★これを使う

**記事のURLを、単独の行に貼るだけ。** noteが自動でカード表示に変換する。
タイトル・見出し画像つきのカードになるので、テキストリンクよりクリックされる。

```
次の話はこちらです。

https://note.com/xxxxx/n/xxxxxxxx      ← この行にURLだけ。前後は空行
```

前後に文章を続けて書くとカードにならないことがあるので、**URLは必ず1行に単独で置く**。

### 2. マガジン

シリーズ用にマガジンを1つ作り、全話を入れる。
記事の下にマガジンが表示され、そこから他の話に飛べる。

**手動リンクと違って、後から記事を追加するだけで全話の導線が自動で繋がる。**
手間が最小なので、必ず作る。

### 3. 固定記事（プロフィールのピン留め）

プロフィールに1記事だけ固定表示できる。
**「寄り道だらけの経歴」を固定する。** インプレッション637で、現状いちばんの入口。

---

## 運用ルール ★これを忘れると導線が切れる

**新しい話を公開したら、前の話の末尾に「次はこちら」を追記する。**

noteは公開後も編集できる。Part 3 を出したら、Part 2 を開いて末尾にリンクを足す。
これをやらないと、読者は Part 2 で行き止まりになる。

| 公開したら | 更新する記事 |
|---|---|
| Part 2 | Part 1 の末尾 |
| Part 3 | Part 2 の末尾 |
| Part 4 | Part 3 の末尾 |
| Part 5 | Part 4 の末尾 ＋ 自己紹介記事の一覧 |

---

## 貼るテキスト

### 各話の末尾（Part 1〜4）

```

──────────

「デザイナーから、トレーニングジムの店長になるまで」全5話

次の話はこちらです。

（次の話のURLを1行で貼る）
```

### 各話の冒頭（Part 2以降）

```
このシリーズの1話目から読む方はこちらです。

（Part 1のURLを1行で貼る）

──────────

```

### 最終話（Part 5）の末尾

```

──────────

「デザイナーから、トレーニングジムの店長になるまで」全5話、これで完結です。

最初から読む方はこちらです。

（Part 1のURLを1行で貼る）
```

### 自己紹介記事「寄り道だらけの経歴」の末尾

いちばんの入口なので、ここから全部に飛べるようにする。

```

──────────

この経歴の中身を、連載で書いています。

「デザイナーから、トレーニングジムの店長になるまで」

（Part 1のURLを1行で貼る）
```

---

## 注意

- リンクを貼りすぎない。1記事につき1〜2本まで。多いと宣伝くさくなる
- 本文の途中には入れない。末尾（と、シリーズものは冒頭）だけ
- 「ぜひ読んでください」と押さない。置くだけでいい

---

## 組織あるある観察記（短編シリーズ）

連載ものではないので「次はこちら」の必然性は弱いですが、
**関連する回だけは相互にリンクを張る**と読まれる本数が増えます。

| 公開したら | 更新する記事 | 状態 |
|---|---|---|
| #2「ジョブ型」（2026/9/24 公開） | #1「風通し」の末尾 | **未対応（#2のURL待ち）** |

### 貼るテキスト（短編用）

```

──────────

組織について書いた別の記事もあります。

（ここにURLを単独行で貼る）
```

※ URLを単独行に置くと埋め込みカードになります（詳細はこのファイル冒頭）。
