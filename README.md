# kuro — 作業用リポジトリ

note記事の執筆と、日々の作業（画像・データ抽出・Excel分析）をここで回します。

## ディレクトリ

```
note/
  STYLE.md        文体・トンマナのルール（最重要。ここを更新すると全記事に効く）
  MONETIZATION.md 公開範囲（無料/有料）の方針。個人特定リスクの扱いもここ
  TEMPLATE.md     記事の基本雛形
  CHECKLIST.md    公開前チェックリスト
  templates/      型別の雛形（ハウツー／体験談／リスト／考察）
  articles/       実際の記事（1記事1ファイル）
work/
  LOG.md          作業ログ（依頼と結果の記録）
  inbox/          素材の置き場（画像・Excel・CSVなど）
  output/         成果物の置き場
```

## 使い方

### note記事をつくる

テーマを投げてください。こちらで型を選び、`note/articles/` に下書きを作ります。

```
「◯◯について書きたい」
→ 型の提案 + note/articles/YYYY-MM-DD-スラッグ.md を作成
→ 見出し・リード・本文の骨組みまで埋めた状態で渡します
```

標準の型は **エッセイ・思索型**（`note/templates/05-essay.md`）です。
`note/STYLE.md` に文体ルールをまとめてあるので、迷ったらそこを見てください。
別の型にしたい場合は「ハウツーで」「リスト記事で」のように添えてください。

### 作業を頼む

`work/inbox/` にファイルを置く、またはチャットに直接添付して依頼してください。

| 依頼 | できること |
|---|---|
| 画像からデータ抽出 | 表・レシート・スクショ・手書きメモを読み取り、CSV / Excel に整形 |
| Excel分析 | 集計・クロス集計・グラフ作成・整形・複数ファイルの突合 |
| 図・グラフ作成 | グラフ、図解、バナー、サムネイルを画像ファイルとして出力 |
| 文書作成 | Word / PowerPoint / PDF の作成・編集・読み取り |

結果は `work/output/` に置き、`work/LOG.md` に1行残します。

補足: 写真やイラストを生成するAI画像生成はこの環境にはありません。グラフ・図解・
文字主体のサムネイルなど、コードで描けるものは画像ファイルとして出力できます。
